list: `textValue({ field })`, a field's value as a Watched and a Set, and `filtered({ list, query, matches })`, the keys
of a list a query keeps, with holds of its own (a combobox, case 5).

keybinds: `palette()`, a command palette over the commands keybinds binds, and `contextMenu()`, a right-click menu of
them, each opened by a command the app binds. A `RightClick` binding that runs now keeps the browser's own context menu
from opening.
